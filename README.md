# Projeto Foto
Projeto desenvolvido durante um evento da DevClub com o objetivo de praticar HTML, CSS e JavaScript.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

## Objetivo
Criar uma página web aplicando conceitos de estrutura, estilização e interatividade.

## Aprendizados
- Organização de arquivos
- Estrutura HTML
- Estilização com CSS
- Manipulação básica com JavaScript
